# Mumzworld AI Support System (Track A)

## 🚀 Overview
AI-powered multilingual customer support system with:
- Intent classification using embeddings
- Lightweight RAG for FAQs
- Confidence-based fallback handling
- English + Arabic responses

---

## 🧠 Features
- Semantic intent detection (not keyword-based)
- RAG-based FAQ retrieval
- Confidence scoring + unknown fallback
- Bilingual response generation
- Evaluation pipeline
